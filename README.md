# TimeMetroidvaniaDemo

一个以局部时间操控为核心的 2D 横版类银河战士恶魔城 Vertical Slice。

## 开发环境

- Unity 6.3 LTS（6000.3.24f1）
- Universal 2D / URP
- Unity Input System 1.20.0
- 首发目标：Windows PC

## 当前阶段

第一阶段：项目基线与玩家移动灰盒。

当前只验证输入、2D 物理、移动、跳跃和相机跟随，不提前实现战斗、敌人、Boss 或时间系统。

## 运行项目

使用 Unity Hub，通过 Unity 6000.3.24f1 打开项目根目录。不要使用其他 Unity 版本升级工程。
