## A2 动画生成的暂存模板

**暂不批量执行。** 先在 A1 小样中确认逻辑像素密度、角色有效高度、统一画布和脚底基线，再把占位符换成确定数字。横砍、上砍、下劈必须分开生成；画面刀光需与 Unity 独立攻击框核对。

三方向动作稿先只画角色身体与指针武器，**不把大面积刀光烘进角色帧**。刀光是独立表现层，以当前玩家攻击框的世界尺寸约束：右向横砍中心在玩家前方 0.9、范围 1.65×1.84；上砍中心在玩家上方 0.75、范围 0.95×1.10；下劈中心在玩家下方 0.75、范围 0.95×1.10。上砍和下劈应围绕身体中线，不画偏向右侧或伸出这些范围的大弧线。武器动作姿势也不能暗示框外有伤害。最终数值以 `PlayerCombat`、`PlayerAttackHitbox2D` 与 `PlayerSlashVisual` 的当前实现复核；角色帧、刀光和碰撞框分开校验。

```text
仅以附件中已确认的 V2 主角母版和通过验收的右向标准姿势为身份参考。制作一种动作：“{动作名称}”，面向右侧，共{已确认帧数}帧，每帧统一{已确认宽}×{已确认高}逻辑像素画布。所有帧角色比例、兜帽轮廓、黑影区域、两根蓝色指针、短旅袍、脚底基线和武器长度一致；身体中心稳定，角色和武器完整不裁切。分清身体运动、头部走针和背负／出鞘武器三个职责；如果无法准确分层，先只交付动作参考，不伪称最终分层 Sprite Sheet。真正透明 Alpha、清晰硬边、无柔光或运动模糊、无背景或文字。只生成这一种动作，不混入其他动画。
```

建议顺序：待机 → 跑步 → 跳跃／下落 → 横砍／上砍／下劈 → Dash／受击；之后再做死亡、治疗和时缓蓄力。正式动画资源统一放在 `Assets/_Project/Animations/V2/`，原始生成稿留在 `ArtSource/V2/`。

## 站姿武器共线约束（2026-09-28 用户修正）

指针武器是一根完整刚性直杆。身体两侧露出的刀尖、杆身与圆形配重中心必须共线，不能分别根据肩部和手腕方向绘制。被身体遮挡的中段仍应能沿同一轴线连接。左右翻转必须同时翻转整根武器及其挂点。

当前试玩待机采用 `Player_Idle_Layered_v03.png` 的无武器身体帧，跑步采用 `Player_BodyLayers_v05.png` 下排身体帧；二者共用 v03 的同一根完整直杆武器。不要再以 v01、v02 或 `Player_Run_Layered_v04.png` 上排的旧站姿武器为几何依据。六帧跑步的武器长度和粗细不变，只改变握点与摆动角度。其他自带武器的动作隐藏分层武器，避免重复出现两把。

后续用户允许平时背负，当前以 v06 背负方式为准：待机与跑步武器斜背在身后，双手自然摆动；武器只随背部轻微摆动，不跟随手臂大幅挥动。攻击时的握持及拔出仍按独立攻击动作制作。
