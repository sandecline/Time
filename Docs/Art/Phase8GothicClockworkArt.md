# 阶段 8：原创哥特钟表遗迹素材制作

## 一、制作顺序

1. 先生成全局风格设定板，锁定配色、像素密度和视觉语言。
2. 使用风格设定板生成主角、三类敌人和 Boss 的标准设定稿。
3. 每次只生成一种动画，并始终附上对应标准设定稿。
4. 生成弹幕、检查点、能力道具、三个区域 Tile、背景、UI 与时间特效。
5. 原图保存在 `ArtSource/ChatGPT`；清理、裁切并统一尺寸后的 PNG 才放入 `Assets/_Project/Art`。
6. Unity 动画控制器与 Clip 放入 `Assets/_Project/Animations`。

## 二、统一规格

- 画风：原创哥特钟表遗迹。
- 主角：无性别机械旅人。
- 像素密度：`32 PPU`。
- 基础色：冷灰石材、深海军蓝、旧黄铜、暗银。
- 时间能量：青蓝色。
- 战斗提示：红色近战、黄色重击、蓝色可斩弹、橙色不可斩弹、紫色时间锚。
- 所有透明素材必须是保留 Alpha 的 PNG，不使用棋盘格模拟透明。
- 动画只生成面向右侧版本，左向由 `SpriteRenderer.flipX` 完成。

## 六、导入与验收

`Assets/_Project/Editor/PixelArtTexturePostprocessor.cs` 会自动为 `Assets/_Project/Art` 内的图片设置：

- Texture Type：Sprite。
- Pixels Per Unit：32。
- Filter Mode：Point。
- Compression：None。
- Generate Mip Maps：关闭。
- Wrap Mode：Clamp。
- Alpha Is Transparency：开启。

动画表导入后仍须手动设置为 `Multiple` 并按固定网格切片：主角和普通敌人为 `96 × 96`，Boss 为 `128 × 128`。切片前先检查实际图片是否严格满足规定尺寸，不能用错误网格强行切图。

最终验收需检查：角色基线、身体中心、武器长度、帧数、透明边缘、弹幕灰度辨识度、平台边缘可读性，以及空中攻击没有悬停视觉表现。
