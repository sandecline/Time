# V2 美术制作计划与素材目录

更新日期：2026-09-27。本文记录当时的美术方向与早期素材状态；当前资源接入情况请查看 [项目 README](../../README.md) 和 Unity 可玩场景。开发主计划见 [ProductionPlanV2.md](../Design/ProductionPlanV2.md)。

## 1. 已确认的美术方向

- 简约像素卡通；气氛神秘、安静，带有时间童话感。
- 世界以自然覆盖的钟表遗迹为方向：灰绿、灰色石材、苔藓与少量旧木色，机械元素随流程增加。具体场景设定板尚待确认。
- 主角为蓝色兜帽和短旅袍包裹的黑影。帽内没有面具、五官、表盘底板或刻度，只有两根长短不同的蓝色指针与中心轴。
- 手脚为短小、简单的黑色轮廓，不画人类手指、复杂关节或大靴子。以用户确认稿的比例为准。
- 武器是一体式钟表长指针，尾部为小圆形配重，没有独立剑柄、护手或剑鞘；待机时贴背斜收。
- 指针需要走动。后续将身体、头部指针与武器分层，避免在每一帧身体动画里重复生成不同表情或指针。
- 动作保留跑跳、方向攻击与受击等必要区分，减少装饰摆动、复杂姿态和细碎特效。

用户已认可的是 [主角设定母版](../../ArtSource/V2/01_Player/Player_Design_Master.png)。圆钟头、蓝陶头壳与实体面具方案均为历史探索，不再作为新素材身份参考。

## 4. 后续制作顺序

| 阶段 | 工作与验收 | 当前状态 |
|---|---|---|
| A0 角色定型 | 确认主角造型、配色、手脚、指针与武器收纳，保存母版 | 已完成 |
| A1 标准姿势与分层 | 整理右向待机稿；固定脚底基线和身体中心；拆出无指针身体、两根指针和武器；确定实际游戏显示尺寸 | 待机原稿已生成，其余待制作 |
| A2 小批动画试制 | 先做待机和跑步，再做跳跃、下落、横砍、上砍、下劈、Dash、受击；试播通过后扩展死亡、治疗、时缓蓄力 | 待开始 |
| A3 世界风格验证 | 将主角放进 R1 代表性场景小样，检查灰绿背景、平台层次与可读性；同时验证敌人、Boss、弹幕和 HUD 的色彩关系 | 待开始 |
| A4 分批制作正式素材 | 风格板确认后，制作四类敌人、Boss、场景模块、道具、UI 与特效；每批先验证一组 | 待开始 |
| A5 Unity 整合 | 导入、切片、挂接状态、校准视觉尺寸，完整流程回归与内存检查 | 待开始 |

A1 的走针分层用于后续动画试制：两针共用稳定转轴；角色正常活动时轻微走动，时停时定住，暂停菜单时停止动画。转速在试播时确定，不用指针角度表达精确能量数值。黑色帽内区域必须保持不透明，不能误抠成洞。

动画始终从确认母版和标准立绘延续身份。三方向攻击的刀光沿用攻击框配置；攻击逐帧素材按攻击阶段播放。时钟图层的朝向和旋转独立校验，不能仅靠整张图片左右翻转导致走针反向或转轴漂移。

## 5. 其余素材需求

- 普通敌人共四类：基础近战、快速冲撞、飞行接触、远程射击。已选择“小生物＋遗迹守卫”组合，具体物种和形象尚待设定图确认。
- Boss 保留两阶段及现有行为需求；至少覆盖待机、横扫前摇与出招、起跳砸地、弹幕、时间锚、受击、阶段变化和死亡。独立刀光判定与表现一致。
- 弹幕区分蓝色可斩、橙色不可斩、紫色时间锚，除颜色外还要有不同轮廓。高密度下控制光晕和碎片数量。
- 交互道具包括 R1/R7 时钟检查点、R5 时停道具、捷径开关与门、旋转机关、Boss 场地锁、水面正常与冻结状态。R5 道具的具体外形等待用户补充。
- 场景按既有手工地图制作模块：R1 苏醒庭院、R2 回廊、R3 蓄水庭院、R4 机械室、R5 密室、R6 钟楼中庭、R7 歇息室、R8 守卫大厅。以上是美术主题，不改变房间地形或入口。
- UI 包括生命、时间槽、能力提示、Boss 血条、地图、暂停与标题菜单；特效包括三方向刀光、命中、受击、斩弹、治疗、时缓和时停。

## 6. 正式导入前的规则

- 当前 `PixelArtTexturePostprocessor` 会为整个 `Assets/_Project/Art/` 强制设置 Sprite、32 PPU、Point、无压缩、无 Mip Maps、Clamp。它是当前代码事实，不代表本轮已经确认新的最终像素规格。
- 在 A1 先用现有 32 PPU 做小样验证；若需要改变像素密度，必须同步调整 V2 导入配置，不能只在 Inspector 修改后被重导入覆盖。
- 最终角色画布、有效像素高度、Tile 尺寸和动画帧数在小样通过后锁定；不沿用旧版 96×96、32×32 等规格作为已确认结论。
- 生成图的像素外观不代表严格像素网格。正式素材需统一逻辑像素密度、裁切和脚底基线，不能直接把 1024×1536 原稿当作最终 Sprite。
- 检查真实 Alpha、边缘杂色与光晕，同时在浅色和深色底上预览；保留主角的黑色身体与帽内黑影。
- 在 R1～R7 的 Size 5 与 R8 基础 Size 5.5 下确认角色、指针、平台和弹幕可读；不为适配大原图改动玩家本体缩放、碰撞或地图。
- 本轮交付是确认稿归档、待机原稿和制作计划。分层、走针动画、正式像素尺寸及游戏内替换尚未完成。
