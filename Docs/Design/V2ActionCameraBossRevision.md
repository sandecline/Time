# V2 镜头、动作衔接、飞行怪与 Boss 修订

> 日期：2026-09-27。实施对象为当前 `EightRoomGreybox`，不重建用户手工微调的地图。实施前场景备份位于本机 `Logs/V2ActionRevision/Before_20260927.unity`（日志目录不入 Git）。

## 本轮规则

- 正交镜头尺寸维持 6、跟随阻尼维持 0.18 秒。开始、换房和复活时先应用当前房间限界，再直接定位镜头；相机平滑后的最终坐标仍须钳制。四片无碰撞遮蔽面覆盖视口内房间边界以外的内容，保持开放缺口与“身体完全穿过才换房”的规则。
- Dash 输入缓存 0.15 秒；攻击总长 0.28 秒、有效段结束比例 0.62，未受 Hit-stop 影响时最早约 0.174 秒可取消到 Dash。攻击前摇和有效段不能立即 Dash，但有效段结束后可取消后摇。Hit-stop 不吃掉缓存时间；暂停、受伤、死亡、治疗、换房、水下冻结清除请求。Dash 不给予无敌帧，也不重置平 A 的 0.55 秒冷却。
- 下劈反弹初速为 11；反弹上升与普通跳跃松键截断分开处理。一刀最多反弹一次，不清除水平速度。
- 玩家平 A 可以击中**同一房间**内、实际进入独立攻击框的墙后敌人与可斩弹幕；墙体不会把攻击框裁切。墙后超出攻击框的目标不能命中。远程索敌、开火与普通／Boss 弹幕仍受实体墙遮挡；敌人与 Boss 近战本轮不套用玩家穿墙规则。
- 飞行怪的状态为悬停、追击、受伤、返回、死亡。当前房间内距离 9 进入追击、12 脱离；首次发现仍需视线。追击速度上限 4.2、加速度 18；被有效攻击时受伤硬直 0.22 秒、白闪 0.10 秒。AI 只输出期望速度，实际地形扫掠与位移统一交给 `EnemyMotor2D`。不新增复杂绕墙寻路。
- Boss 横扫和砸地使用各自独立的 Trigger：3.5×2.5／4.7×3.2 世界单位；同一次有效段只伤玩家一次。动作按前摇、行进、有效、后摇推进；红色横扫、黄色落点、蓝色弹幕和紫色时间锚预警与对应判定共用阶段信息。灰盒横扫弧线和砸地冲击线的外沿对齐对应命中框。正常游戏不显示矩形判定框；选中攻击框并开启 Inspector 调试开关后可看真实范围。
- R7 检查点使用子级或程序化时钟表现时，不要求根对象拥有 `SpriteRenderer`；激活规则不变。
