# 阶段 1：玩家战斗灰盒

## 目标

建立“移动—攻击—Dash—受伤—死亡—重生”的最小闭环，并为后续时间槽、治疗和世界时间系统提供稳定接口。

## 当前参数

| 项目 | 数值 |
|---|---:|
| 玩家生命 | 5 |
| 普通攻击伤害 | 1 |
| 攻击总时长 | 0.28 秒 |
| 攻击有效窗口 | 20%～65% |
| Dash 速度 | 15 |
| Dash 时长 | 0.16 秒 |
| Dash 后冷却 | 0.2 秒 |
| 受伤保护 | 0.8 秒 |
| 受击状态 | 0.18 秒 |
| 死亡后重生 | 1.2 秒 |

## 接口

- IDamageable.TryTakeDamage：玩家、敌人与 Boss 的统一伤害入口。
- DamageInfo：携带来源、伤害、命中点和击退速度。
- PlayerStateMachine：拒绝互斥操作，并允许受伤打断攻击或 Dash。
- HealthSystem.SetRespawnPoint：后续检查点系统更新重生位置。

## 手工验收

1. 打开 CombatPrototype 并进入 Play Mode。
2. 用 A/D 接近红色训练假人，按 J；一次挥剑只扣一格生命。
3. 跳起后按 J；空中平砍仍可命中。
4. 面向训练假人按 L；接触仍会扣血并打断 Dash。
5. 对右侧实体墙按 L；玩家不能穿墙。
6. 连续贴住训练假人；受伤保护期间不会连续扣血。
7. 生命归零后等待 1.2 秒；玩家回到起点并恢复满血。
