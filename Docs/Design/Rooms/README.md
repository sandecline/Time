## 通用约定

- 阴影区域为实体墙体或地面，黑色短线为可站立平台或局部墙体；具体含义以对应房间文档为准。
- 普通入口是墙体真实缺口。玩家穿过边界后换房，不显示传送门，也不要求按键。
- 镜头在房间边界内平滑跟随玩家，房间默认大于单个镜头视野，不直接展示完整布局。
- 上下房间切换保留合理的进入动量；从下方跳入新房时，根据进入瞬间的朝向或水平输入确定跳出方向。
- 进出房间刷新普通敌人；已开启的捷径、已获得能力和当前检查点不随敌人刷新撤销。
- 草图只决定布局和功能，不锁定 V2 的最终美术主题、Tile 尺寸或 PPU。

## 原图归档规则

- 逐房间文件名固定为 R{编号}_Original.png；总览使用 WorldMap_Overview_Original.png。所有文件保存聊天中用户提交的原始图片，不进行裁切或重绘。
- 后续修订不会覆盖原图，而是在房间文档中追加规则；若用户提交新版草图，使用带日期或版本号的新文件名。
