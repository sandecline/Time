# R7：Boss 前存档点房

![R7 原始草图](Sketches/R7_Original.png)

> 状态：布局、入口与存档点规则已确认，等待灰盒制作。

## 连接与地形

- 右下角开放缺口连接 R6 的右上出口，是本房间唯一入口和出口。
- 房间由封闭墙体和底部地面组成，草图未标注额外平台、敌人或伤害机关，因此按安全休息房制作。
- 镜头仍在房间边界内跟随玩家；不为了展示全貌而改变通用镜头尺度。

## 时钟存档点

- 蓝色图案是时钟状存档装置，与 R1 的初始装置属于同一系列。
- R1 装置的指针指向 `0`，表示新运行的初始点；R7 装置的指针指向 `1`，用于清楚区分 Boss 前存档点。
- 玩家靠近后按 `W` 交互，激活 R7 作为本次运行的最新复活点，同时执行检查点休息与敌人刷新规则。
- 当前 V2 测试版不写磁盘文件；“存档”仅在本次运行中有效。重新加载场景或退出 Play Mode 后重置。
- 激活后从 R8 死亡应在 R7 复活；未激活时仍回到 R1 初始点。

## 灰盒验收

- 玩家从 R6 进入后能够安全抵达存档点，不会被敌人或机关打断。
- 只有玩家进入交互范围并按 `W` 时才激活，经过房间或远程按键不能误触。
- 激活反馈应明确显示指针、灯光或 HUD 状态变化；最终表现等待 V2 美术确认。
- 反复使用存档点不会重复授予能力，也不会改变已确认的 Boss 胜利状态。
