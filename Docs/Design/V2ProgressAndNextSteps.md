## 二、当前测试结果与已知问题

- Unity 已完成编译及场景迁移。
- 当前 EditMode：**68 / 68 通过**。
- 当前 PlayMode：**21 / 21 通过**。
- 上次唯一失败的“远程弹幕遇到薄墙回池且视线受阻”已通过，包括后续弹幕发射／回池断言。
- 修复 `WorldCollision2D.Blocks`：不再用零半径 CircleCast 检测视线，改用 Raycast；有体积弹幕保留 CircleCast；显式查询起点重叠，避免全局起点查询开关导致嵌墙漏检。忽略水体等 Trigger 和非 Ground 碰撞体。
- 新增 11 项 EditMode 用例和 3 项 PlayMode 集成用例，覆盖普通墙／薄墙、双向查询、起点嵌墙、体积贴墙、非遮挡物过滤，以及实际索敌、开火、玩家伤敌／斩弹、高速 Boss 弹幕与对象池复用。
- 2026-09-27 最新结果来自 Unity Test Runner：EditMode 68/68、PlayMode 21/21。此前 PlayMode 17/17、EditMode 67/67、PlayMode 14/14 以及更早的 XML 均为历史结果。
- 本次新测了两阶段扇形、落雨、交叉弹幕及时间锚数量，每刀斩 20 枚 Boss 蓝弹的 16 点上限，以及阵型拉远和重置后的镜头尺寸。完整数值见 [V2BossDenseBulletRevision.md](V2BossDenseBulletRevision.md)。
- 本轮不是完整通关、跨帧率或性能验收。没有据此宣布 V2 已完成。
- 新修订的设计与交接见 [V2ActionCameraBossRevision.md](V2ActionCameraBossRevision.md)；其中的人工检查清单尚未完成。历史测试结果不代表本轮新增脚本的验收。
