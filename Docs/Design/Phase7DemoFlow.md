# 阶段 7：测试流程与统一 UI

## 当前交付

`SevenRoomSlice` 进入 Play Mode 后先显示标题界面。按 Enter 或点击“开始测试”进入游戏；`Esc` 打开暂停界面，`M` 打开基础七房间地图。死亡期间显示时间回溯遮罩，约 1.2 秒后回到本次运行最近检查点；击败 Boss 后进入测试结尾界面。

## 无持久化约定

当前 Demo 不读取或写入任何存档，不使用 PlayerPrefs，也不创建磁盘文件。“继续游戏”按钮保持禁用。检查点、地图发现、能力和 Boss 状态只在当前运行中有效；停止 Play Mode、返回标题或重新加载场景后全部清空，方便重复测试。

## UI

- 左侧统一显示生命、时间槽、世界时间、治疗／时缓进度和玩家状态。
- 右侧显示当前房间、最近检查点、目标和交互反馈。
- 地图只显示本次运行发现的房间，当前房间使用绿色标记。
- Boss 血条沿用阶段 6 HUD，标题、暂停、地图、死亡与结尾由流程控制器统一管理。

## 验证

- 标题、暂停和地图状态会冻结世界并关闭玩家输入，恢复游戏后时间和输入正常。
- 死亡计时不会被错误暂停；重生后遮罩消失。
- 重新加载场景后只发现房间 1，不恢复上一轮检查点、地图或 Boss 胜利。
- 完整流程能够从标题开始，经过七房间和 Boss，抵达结尾。
