# 阶段 3：世界时间系统

## 目标

在不改变 Unity 全局 `Time.timeScale` 的前提下，完成正常、时缓、时停三种世界状态，并让敌人、投射物、平台、陷阱和 Animator 可以按对象使用局部时间。

## 核心结构

- `WorldTimeService`：维护世界状态、未缩放计时、能力解锁和时停会话。
- `ITimeControllable`：局部时间对象的统一注册接口，同时为后续时间抗性敌人保留入口。
- `LocalTimeController`：提供 `LocalDeltaTime` 与 `LocalFixedDeltaTime`，同步 Animator，并在时停期间冻结 Rigidbody2D。
- `TimeStopSession`：独立记录单次时停的启动成本、最大时长、剩余时间和提前结束退款。
- `TimeAwareDamageReceiver`：时停期间缓存冻结目标受到的伤害，世界恢复后合并结算。
- `PlayerTimeAbilities`：处理 J 长按时缓、I 短按时停和时停攻击扣时。

## 规则

### 时缓

- J 按下仍立即攻击。
- 持续按住 J 满 1 秒，松开后触发时缓。
- 时缓免费，持续 3 秒真实时间，世界对象倍率为 0.35。
- 时缓期间不能再次蓄力。

### 时停

- 短按 I 启动，要求能力已解锁且时间槽至少有 60 点。
- 基础持续 5 秒真实时间；时长升级后为 7 秒。
- 时停覆盖时缓；启动失败时不取消已有时缓。
- 玩家移动、跳跃、Dash 与攻击保持正常速度。
- 时停中每完成一次攻击扣除 0.6 秒剩余时间。
- 时停攻击仍可补充时间槽，但敌人和弹幕的补槽量均降为正常值的 25%。
- 时停中再次按 I 立即结束，并返还 `floor(60 × 剩余时间 / 本次最大时间)` 点时间槽。
- 自然耗尽时不返还时间槽。

## 灰盒验收

`CombatPrototype` 中的训练假人接入局部时间和延迟伤害，可斩投射物会水平往返移动。触发时缓或时停后可以直接观察其速度变化；时停期间投射物仍能被斩掉，假人所受伤害在恢复时间后统一结算。HUD 会显示世界模式、能力剩余时间和时缓蓄力进度。
