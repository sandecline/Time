# 阶段 2：时间槽与治疗

## 核心规则

| 项目 | 数值 |
|---|---:|
| 时间槽上限 | 100 |
| 平砍有效命中 | +8 |
| 斩掉可破坏弹幕 | +4 |
| 治疗最低启动资源 | 60 |
| 短按/长按分界 | 0.3 秒 |
| 正式治疗时间 | 1.5 秒 |
| 完整治疗消耗 | 60 |

时间槽不会自然恢复。玩家死亡时清空，重生后保持为零。

## 输入顺序

1. 按下 I 后开始记录现实按住时长。
2. 在 0.3 秒内松开，只发出时停请求。
3. 达到 0.3 秒后，不再触发短按，尝试进入治疗。
4. 治疗进入后再持续 1.5 秒，时间槽从 60 线性扣至 0。
5. 完成后直接恢复满血。

阶段 2 只建立短按事件；世界时停的成本、持续时间和返还公式在阶段 3 接入。

## 中断规则

- 松开 I。
- 受到伤害。
- 离开地面。
- 玩家进入其他互斥状态。
- 治疗过程中资源因外部原因不足。

所有中断均不返还已经消耗的时间槽。

## 灰盒验收

1. 打开 CombatPrototype。
2. 攻击红色训练假人，每次有效攻击获得 8 点；受伤保护挡住的重复命中不补槽。
3. 斩掉左侧青色弹幕，获得 4 点。
4. 与训练假人接触损失生命，积累至少 60 点后长按 I。
5. HUD 在治疗期间显示进度，约 1.8 秒总按住时间后恢复满血并消耗 60 点。
6. 治疗中提前松开或碰到训练假人，确认治疗中断且已消费资源不返还。
7. 在 0.3 秒内短按 I，Console 只显示时停请求，不进入治疗。
