# 主角概念设定

> 本文为 Demo1 历史设定。V2 已确认蓝袍黑影主角，当前依据见 [V2 美术制作计划](../Art/V2ArtProductionPlan.md)。下文的钟表头、盔甲与旧像素规格不作为 V2 要求。

## 已确认设定

- 主角体型与屏幕占比参考《空洞骑士》《铲子骑士》的主角尺度，保持小巧、轮廓清晰、适合横版动作战斗。
- 整体采用原创哥特钟表遗迹风格：冷灰石材、深海军蓝、旧黄铜、暗银与青蓝色时间能量。
- 主角是无性别机械旅人，穿深海军蓝轻甲、冷灰内衬和短小残破斗篷，四肢纤细，黄铜关节保持轻快轮廓。
- 头部为蓝色钟表造型，是角色最主要的视觉识别点；表盘使用四个粗大刻度和两根清晰指针，不依赖细小刻度传达特征。
- 武器为钟表分针构成的单手剑，主体使用暗银与旧黄铜，刃口带少量青蓝色时间能量。
- 当前灰盒角色的 `1 × 1.6` 比例继续作为碰撞体和关卡尺度基线，正式美术可以在不改变物理尺寸的情况下替换。
- 正式像素素材统一按 `32 PPU` 制作；主角动画使用 `96 × 96` 单帧画布，角色脚底基线与身体中心保持稳定。

## 美术与动画约束

- 身体、钟表头和分针剑应尽量拆分为独立 Sprite 层，便于待机、转向、攻击和受击动画制作。
- 小尺寸画面下必须优先保证钟表头与分针剑的轮廓可读性，避免依赖细小表盘刻度传达角色特征。
- 角色碰撞体、攻击判定和美术轮廓保持分离，避免更换动画后影响移动与战斗数值。
- 仅参考同类作品的角色尺度与可读性，不直接复制已有角色的服装、轮廓或动作设计。
- 所有基础动画只制作面向右侧版本，左向由 `SpriteRenderer.flipX` 完成。
- 空中平砍动画不得表现悬停、顿挫或空中刹车；Dash 动画不得使用代表无敌的闪烁或角色透明。
- 普通、受伤、时缓蓄力和时停使用不同的表盘发光状态，但不改变角色主体配色。

## 仍需在原画确认后微调

- 分针剑的最终视觉长度以现有攻击判定为上限，不因图片尺寸扩大实际攻击距离。
- 表盘指针的静态角度和受击表情只做可读性调整，不增加新的玩法含义。
- 身体、钟表头和分针剑的最终拆层方式在第一版动画原稿完成后确定。
