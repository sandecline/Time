# 《时序旅人》Windows Demo 打包

当前入口场景为 `Assets/_Project/Scenes/V2/EightRoomArtPreview.unity`，构建目标为 Windows x64。

在 Unity 编辑器中选择 **Tools → 时序旅人 → 构建 Windows Demo**。完成后运行 `Builds/Windows/时序旅人.exe`。

分享试玩包时，请把整个 `Builds/Windows` 文件夹一起压缩；`时序旅人_Data`、`UnityPlayer.dll` 等文件须与 EXE 保持原有相对位置。当前 Demo 的检查点与 Boss 进度只在本次运行内有效，关闭后从开头重新开始。
