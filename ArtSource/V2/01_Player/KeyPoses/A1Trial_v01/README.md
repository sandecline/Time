# 主角右向待机 A1 图层试样 v01

来源：已确认主角母版及 `Player_Idle_Right_LayerReference_v01.png`。本目录保留为可直接修改的小样，未导入 Unity，也未替换现有角色。

| 文件 | 用途 |
|---|---|
| `Player_Idle_Right_Body.png` | 无帽内指针、无武器的身体 |
| `Player_Idle_Right_ClockHands.png` | 两根蓝色指针和中心轴 |
| `Player_Idle_Right_Weapon.png` | 背负的单根钟表长指针 |
| `Player_Idle_Right_Composite.png` | 按武器 → 身体 → 双针顺序叠加的检查图 |

四张图均为 64×80 RGBA，同一画布，Alpha 只有 0 和 255。脚底基线为 y=74；两针共用的暂定转轴为 (41,27)。从 1774×887 参考板裁切、对齐并降采样为逻辑像素，小样尺寸尚未经过游戏内验证，32 PPU 也未确定为 V2 最终规格。

正式使用前仍需核对武器收纳位置、角色在 R1～R7 与 R8 镜头中的实际大小、走针旋转、浅色和深色背景下的边缘，以及与当前玩家判定框的视觉关系。不要把本目录当作已验收的正式 Sprite。

## Unity 灰盒镜头预览

- `Player_Idle_Right_R1_Size5_Preview_v02.png`：1920×1080，R1 镜头 Size 5；仅在截图时将玩家移到初始检查点右侧，避免青色检查点图形遮挡。
- `Player_Idle_Right_R8_Size5_5_Preview_v02.png`：1920×1080，R8 镜头 Size 5.5；仅在截图时将玩家移到 Boss 左侧地面附近。
- 两张图均由 Unity 6000.3.24f1 在八房间灰盒场景中渲染，临时使用 32 PPU、当前玩家显示缩放和 A1 组合图。截图时没有保存场景或预制体更改，也没有替换旧动作动画。
- 这是静态编辑器镜头检查，不等于 Play Mode 的动作试播。当前灰盒背景较暗，黑色手脚的可读性偏弱；背负武器在正常镜头下主要能看到尾部亮点，整根指针不够明显。后续需先处理这两个视觉问题，再锁定尺寸或进入批量动画。
