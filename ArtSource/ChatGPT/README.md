# ChatGPT 原始美术素材

这里保存 ChatGPT 输出的未清理原图和设定稿。原图不得直接接入 Unity 场景；完成像素清理、透明通道检查、裁切和尺寸统一后，再复制到 `Assets/_Project/Art` 对应目录。

目录用途：

- `00_StyleReference`：全局风格和色板设定。
- `01_Player`：主角设定与动画原稿。
- `02_Enemies`：三类普通敌人。
- `03_Boss`：时蚀守卫。
- `04_Projectiles`：蓝、橙、紫弹幕。
- `05_Environment`：Tile 与背景原稿。
- `06_Props`：检查点、能力核心和装饰物。
- `07_UI`：HUD、菜单与地图图标。
- `08_VFX`：攻击、时间、治疗和死亡特效。

完整提示词见 `Docs/Art/Phase8GothicClockworkArt.md`。
